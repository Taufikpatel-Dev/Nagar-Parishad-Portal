# Nagar Parishad Digital Seva Portal - Demo Script

**Estimated Time:** 5 Minutes

## Flow

1. **The Homepage & Multi-Tenancy (1 min)**
   - Start at the `Home` page (`/`).
   - Highlight the branding, language toggle (Marathi/English), and accessibility tools.
   - **WOW Moment:** Click the municipality dropdown in the header to switch between Pandharpur, Sangola, etc. Show how the logo, theme color, helpline numbers, and stats change instantly without reloading.

2. **Citizen Complaint Flow (1 min)**
   - Click **Register Complaint** from the home page grid.
   - Point out the guest flow (mobile number input).
   - Fill the form and submit.
   - Show the generated Complaint ID (e.g., `PDH-CMP-...`) and copy it.

3. **Public Tracker (30 sec)**
   - Go to **Track Status** (`/track`).
   - Paste the Complaint ID or use the sample `PDH-CMP-002`.
   - Show the detailed Stepper / Timeline view that doesn't require a login.

4. **Property Tax Payment & PDF/QR (1 min)**
   - Go to **Property Tax Payment** (`/services/property-tax`).
   - Enter a dummy property number (e.g., `PDH-PROP-001`).
   - View details and click **Pay Now**.
   - Show the payment success state.
   - **WOW Moment:** Click **Download Receipt PDF**. Point out the official letterhead layout and the generated QR code.

5. **Admin Dashboard (1.5 min)**
   - Navigate to **Admin** (`/admin/dashboard`).
   - Show the Overview tab: Recharts (pie chart, trend line, ward-wise bars).
   - Point out the **Escalated** metric card.
   - Switch to the **Complaints** tab. Highlight the red "Escalated" badge on delayed complaints.
   - Switch to the **Activity Log** tab to show the audit trail of what admins have been doing.
